# Doodle Dinos — Voiceover Script & Audio Pack

Record (or generate with a neural voice) each line below and save it with the
**exact filename** shown. The app automatically plays a clip when the file
exists, and falls back to the device voice when it doesn't — so you can add
clips gradually and nothing ever breaks.

## How to add the clips
1. Create a folder named **`audio`**.
2. Save every file as **MP3** with the exact name shown (lowercase).
3. **In the app / browser test:** put the `audio` folder right next to
   `doodle-dinos.html`.
4. **In the Android project:** put the files in
   `app/src/main/assets/audio/` (create the `audio` folder), then rebuild.

## Tips for a warm, kid-friendly voice
- A real person (a parent/teacher) reading slowly and cheerfully is ideal.
- Or use a **neural TTS** (e.g., ElevenLabs, Google Cloud, Azure) — pick a soft,
  friendly female or child-style voice. Avoid the basic robotic "system" voices.
- Keep clips short, upbeat, and clearly enunciated. Leave a tiny pause at the start/end.
- ~22kHz mono MP3 is plenty; keeps the app small.
- **English is wired up first.** The other six languages keep the device voice
  until you add their packs (ask me to extend the map when ready).
