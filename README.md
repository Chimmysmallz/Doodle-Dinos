# Doodle Dinos (test site)

Safe, joyful play for ages 1 to 6. Offline, ad-free, no data collected.

This folder is a complete GitHub Pages site. It contains:

| File | What it is |
|---|---|
| `index.html` | The whole app in one file |
| `privacy-policy.html` | The privacy policy (fill in your name, email and date before launch) |
| `audio/` | Optional recorded clips. Empty is fine. |
| `TESTING.md` | The end-to-end test checklist |
| `.nojekyll` | Tells GitHub to publish the files exactly as they are |

## Put it online (about 5 minutes)

1. Sign in at github.com with your **personal** account.
2. Click **+** (top right), then **New repository**. Name it `doodle-dinos`, set it to **Public**, and click **Create repository**.
3. On the new repository page, click **uploading an existing file**.
4. Unzip this download. Open the `doodle-dinos` folder, select **everything inside it** (including the `audio` folder), and drag it onto the GitHub page. Click **Commit changes**.
   - The `.nojekyll` file is hidden on most computers. If it does not upload, the site still works.
5. Go to **Settings**, then **Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
6. Wait one or two minutes and refresh. GitHub shows the link: `https://<your-username>.github.io/doodle-dinos/`

Your privacy policy link for the Play Console will be:
`https://<your-username>.github.io/doodle-dinos/privacy-policy.html`

## Test on your iPhone

1. Open the link in **Safari** (not Chrome).
2. Tap **Share**, then **Add to Home Screen**, then **Add**.
3. Work through `TESTING.md`.

Tip: test **Parent Voice recording** in the Safari tab, not from the home-screen icon. iPhone limits the microphone for home-screen web apps.

## Update it later

Upload a new `index.html` to the same repository (**Add file**, then **Upload files**, then **Commit**). The site updates in about two minutes. If the iPhone still shows the old version, close the app fully and reopen it.
